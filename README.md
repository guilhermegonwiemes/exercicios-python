## Descrição:
Este repositório contém 25 exercícios em python, feitos para uma atividade escolar. Estes exercícios abordam diferentes tópicos como variáveis, condicionais, repetições e arrays.

## Tecnologia Utilizada:

 - Python 3.14.3

## Como executar:

 1 - Entre no programa "Visual Studio Code "
 2 - Abra a aba de "versionamento" ou "source control" no menu da esquerda do programa 
 3 - Escolha o repositório à importar e qual pasta do seu computador importar os arquivos
 4 - Após importar os arquivos, escolha o arquivo com extensão ".py" que desejar executar
 5 - Após clicar no arquivo que desejar executar, vá até o canto superior direito da janela do código
 6 - No canto superior esquerdo, clique no botão "Run Python File", representado por um símbolo de "play"
 7 - O programa estará rodando no terminal do Visual Studio Code, caso o programa peça que você digite algo, faça-o, de acordo com o que a exigência no terminal disser
